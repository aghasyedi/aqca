3-Qubit Error Correction Codes

Fault Tolerance

1. Overview & Problem Definition

The 3-Qubit Bit-Flip and Phase-Flip Codes are the foundational protocols for Quantum Error Correction (QEC).

The problem they solve is environmental noise. In classical computing, if a bit flips due to radiation, we use a repetition code: copy the bit three times (e.g., 111). If one flips to 101, we take a majority vote and correct it back to 1. In quantum computing, we face two massive roadblocks:

  • The No-Cloning Theorem: We cannot copy an unknown quantum state.
  • Measurement Collapse: If we measure a quantum state to see if an error occurred, we destroy the superposition.

Error Type Addressed

Single-Qubit

Can detect and correct exactly one error per block. Fails if two errors occur.

Qubit Overhead

3 to 1

Requires 3 physical qubits to protect 1 logical data qubit.

Ancilla Overhead

2 qubits

Requires 2 additional auxiliary qubits for non-destructive measurement.

2. Intuition

If we cannot copy the state, and we cannot measure the state, how do we protect it? We use entanglement as redundancy.

Instead of copying the state, we spread the information of a single qubit across a highly entangled state of three qubits. If a stray magnetic field flips one of the qubits, we do not measure the qubits directly. Instead, we measure the relationships (the parity) between them using temporary helper qubits (ancillas).

Think of it like three people holding hands in a dark room. You cannot see their faces (the data), but if you ask, "Are the first two people standing or sitting?" they can answer "We are doing the same thing" or "We are doing different things" without revealing what they are doing. This is called syndrome measurement. If qubits 1 and 2 disagree, but qubits 2 and 3 agree, logically, qubit 1 must be the one that flipped.

(Note: The Phase-Flip code is identical to the Bit-Flip code, but we wrap the entire protocol in Hadamard gates to change the basis from \(Z\) to \(X\).)

3. Required Gates & Circuit Schematic

  • Controlled-NOT (\(CX\)): Used both to entangle the initial state (encoding) and to extract the parity information without collapsing the data.
  • Hadamard (\(H\)): Used exclusively in the Phase-Flip code to swap between the computational basis (where bit-flips happen) and the phase basis.
  • Measurement (\(M\)): Applied only to the ancilla qubits.

4. Mathematical Proof & State Evolution

Step 1: Initialisation & Redundant Encoding

The 3-Qubit Bit-Flip Code protects a fragile logical qubit state $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$ from a single bit-flip error. Due to the No-Cloning Theorem, we cannot duplicate the qubit. Instead, we use quantum entanglement.

We append two auxiliary $|0\rangle$ qubits, making the initial state:

\[ |\Psi_{init}\rangle = (\alpha|0\rangle + \beta|1\rangle) \otimes |00\rangle = \alpha|000\rangle + \beta|100\rangle \]

Two Controlled-NOT (CX) gates encode the state by spreading the information non-locally:

\[ |\Psi_{enc}\rangle = CX_{0,2} CX_{0,1} (\alpha|000\rangle + \beta|100\rangle) = \alpha|000\rangle + \beta|111\rangle \]

The amplitudes $\alpha$ and $\beta$ are now safely distributed across all three physical qubits.

Step 2: The Quantum Error Channel

If a single bit-flip (Pauli $X$) error occurs on any of the qubits, the state evolves deterministically. Because the error operator $E_i$ acts linearly, the superposition coefficients $\alpha$ and $\beta$ remain completely unchanged.

For example, if an error hits Qubit 0 ($E_0 = X \otimes I \otimes I$):

\[ |\psi_{err}\rangle = E_0 (\alpha|000\rangle + \beta|111\rangle) = \alpha|100\rangle + \beta|011\rangle \]

Similar distinct orthogonal states are produced if the error hits Qubit 1 ($|010\rangle, |101\rangle$) or Qubit 2 ($|001\rangle, |110\rangle$).

Step 3: Syndrome Extraction (Parity Measurement)

To detect the error without measuring the data qubits (which would irreversibly collapse $\alpha$ and $\beta$), we measure the **parity** between adjacent qubits using two ancilla qubits.

• Parity 1 ($S_1 = Z_0 Z_1$): Compares Qubit 0 and Qubit 1.

• Parity 2 ($S_2 = Z_1 Z_2$): Compares Qubit 1 and Qubit 2.

We apply a sequence of CX gates from the data qubits to the ancilla qubits. For the Qubit 0 error case ($\alpha|100\rangle + \beta|011\rangle$), the parity extraction strictly factors out the ancilla state:

\[ |\Psi_{eval}\rangle = \Big( \alpha|100\rangle + \beta|011\rangle \Big) \otimes |10\rangle_{anc} \]

Because the ancilla state $|10\rangle_{anc}$ is identical for both the $\alpha$ and $\beta$ branches, it fully factors out of the superposition.

Step 4: Deterministic Correction & Decoding

Measuring the ancilla qubits yields a 2-bit classical string called the **syndrome**. For our example, we measure `10` with 100% probability.

Because the measurement yields no information about $\alpha$ or $\beta$, the quantum superposition remains perfectly intact. The classical syndrome acts as an exact lookup key for the recovery operator:

* `00` $\to$ No Error ($I$)

* `10` $\to$ Error on Qubit 0 ($X_0$)

* `11` $\to$ Error on Qubit 1 ($X_1$)

* `01` $\to$ Error on Qubit 2 ($X_2$)

We apply the required Pauli $X_0$ correction, perfectly restoring the encoded logical state:

\[ X_0 \Big( \alpha|100\rangle + \beta|011\rangle \Big) = \alpha|000\rangle + \beta|111\rangle \]

Applying the CX gates in reverse perfectly uncomputes the auxiliary qubits, cleanly recovering the initial state $|\psi\rangle = \alpha|0\rangle + \beta|1\rangle$.

5. Interactive Visualisation

  • Bloch Spheres (No-Cloning): If you watch the three physical data qubits individually, their Bloch vectors will shrink to the centre of the sphere the moment they are encoded. Because they are maximally entangled, their local states become completely mixed. The information now lives in the global state, not the individual qubits.
  • Amplitude Histogram: During the error, the probability bars for \(|000\rangle\) and \(|111\rangle\) vanish, replaced by bars for \(|100\rangle\) and \(|011\rangle\). The moment the classical correction is applied, the bars instantly snap back to the correct \(|000\rangle\) and \(|111\rangle\) positions, regardless of the values of \(\alpha\) and \(\beta\).

6. Python Code Implementation

Qiskit Program 
import numpy as np

def simulate_bit_flip_code(alpha, beta, error_qubit):
    """
    Simulates the 3-Qubit Bit-Flip code via state vectors.
    """
    X = np.array([[0, 1], [1, 0]], dtype=complex)
    I = np.eye(2, dtype=complex)
    
    # 1. Encoding (assuming we start with alpha|000> + beta|111>)
    state = np.zeros(8, dtype=complex)
    state[0] = alpha # |000>
    state[7] = beta  # |111>
    
    # 2. Apply Error
    if error_qubit == 0:
        error_op = np.kron(np.kron(X, I), I)
    elif error_qubit == 1:
        error_op = np.kron(np.kron(I, X), I)
    elif error_qubit == 2:
        error_op = np.kron(np.kron(I, I), X)
    else:
        error_op = np.kron(np.kron(I, I), I)
        
    errored_state = np.dot(error_op, state)
    
    # 3. Simulate Parity Check (Math abstraction of the ancilla measurement)
    # We find which basis states have non-zero amplitude to deduce the error
    non_zero_indices = np.where(np.abs(errored_state) > 1e-5)[0]
    binary_states = [format(idx, '03b') for idx in non_zero_indices]
    
    # Check parities of the first non-zero state (they will be identical for the second)
    sample = binary_states[0]
    parity_01 = int(sample[0]) ^ int(sample[1])
    parity_12 = int(sample[1]) ^ int(sample[2])
    
    # 4. Correction Logic
    correction_op = np.kron(np.kron(I, I), I)
    if parity_01 == 1 and parity_12 == 0:   # Q0 flipped
        correction_op = np.kron(np.kron(X, I), I)
    elif parity_01 == 1 and parity_12 == 1: # Q1 flipped
        correction_op = np.kron(np.kron(I, X), I)
    elif parity_01 == 0 and parity_12 == 1: # Q2 flipped
        correction_op = np.kron(np.kron(I, I), X)
        
    final_state = np.dot(correction_op, errored_state)
    return final_state

# Test: State 0.8|0> + 0.6|1>, Error on Qubit 1
alpha_val, beta_val = 0.8, 0.6
restored = simulate_bit_flip_code(alpha_val, beta_val, error_qubit=1)
print(f"Restored amplitudes: |000> = {restored[0].real}, |111> = {restored[7].real}")

7. Caveats & Real-World Limits

  • Two-Error Failure: The 3-qubit code only assumes one error occurs per cycle. If two bit-flips occur (e.g., 000 becomes 110), the syndrome measurement will incorrectly assume that Q2 flipped, rather than Q0 and Q1. The correction gate will then flip Q2, turning the state into 111 — a catastrophic logical failure.
  • Phase-Flip Vulnerability: The bit-flip code provides zero protection against phase flips (\(Z\) errors). A \(Z\) error does not change the parity of the computational basis, so it goes entirely undetected. The phase-flip code, conversely, provides zero protection against bit-flips.
  • Fault-Tolerant Measurement: The circuit shown above is not strictly fault-tolerant. If one of the CNOT gates used to measure the parity fails, it can inject a new error directly into the data qubits. Real QEC requires carefully constructed flag qubits to catch measurement errors.

8. Applications

  • The Shor Code: The immediate application of these two codes is combining them. By wrapping three Phase-Flip codes inside a massive 9-qubit Bit-Flip code architecture, Peter Shor created the Shor Code — the first protocol capable of correcting arbitrary quantum errors (both bit and phase simultaneously).
  • Pedagogical Foundation: These codes form the mathematical bedrock for understanding stabilizer formalism, which is the mathematical language used to design modern Surface Codes and Color Codes.
