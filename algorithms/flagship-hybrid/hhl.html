HHL Algorithm (Harrow-Hassidim-Lloyd)

Flagship & Hybrid Models

1. Overview & Problem Definition

The HHL Algorithm solves systems of linear equations on a quantum computer. Given a Hermitian \(N \times N\) matrix \(A\) and a known vector \(\vec{b}\), the algorithm finds the solution vector \(\vec{x}\) such that \(A\vec{x} = \vec{b}\).

In modern computation, solving large linear systems is the bottleneck for everything from fluid dynamics and differential equations to machine learning and financial modeling. HHL was a landmark breakthrough because it offered a theoretical exponential speedup over the best known classical algorithms.

Classical Complexity

\(\mathcal{O}(N \kappa)\)

The classical Conjugate Gradient method scales linearly with the number of variables \(N\) (where \(\kappa\) is the condition number of \(A\)).

Quantum Speedup

\(\mathcal{O}(\log(N) \kappa^2 / \epsilon)\)

HHL solves the system in time proportional to the logarithm of \(N\), yielding an exponential speedup, provided the matrix is sparse and well-conditioned.

2. Intuition

If we want to compute \(\vec{x} = A^{-1}\vec{b}\), we can think about this problem in terms of the eigenvalues and eigenvectors of \(A\).

  1. Eigenbasis: Any matrix \(A\) stretches space along specific directions (eigenvectors) by specific amounts (eigenvalues). If we break the vector \(\vec{b}\) into a combination of these eigenvectors, applying \(A^{-1}\) simply means dividing the length of each eigenvector component by its corresponding eigenvalue.
  2. Quantum Parallelism: The HHL algorithm encodes \(\vec{b}\) into the amplitudes of a quantum state \(|b\rangle\). It then uses Quantum Phase Estimation (QPE) to "read" the eigenvalues of \(A\) and write them into a temporary register.
  3. The Inversion: The quantum computer applies a controlled rotation to a separate ancilla qubit. The trick is that the angle of rotation is inversely proportional to the eigenvalues stored in the temporary register.
  4. Cleanup and Collapse: The temporary register is cleared using Inverse QPE. Finally, we measure the ancilla qubit. If it measures as \(|1\rangle\), quantum mechanics dictates that the rest of the system collapses exactly into a state proportional to \(A^{-1}|b\rangle\), our solution.

3. Required Gates & Circuit Schematic

  • State Preparation (\(U_b\)): A unitary that encodes the classical vector \(\vec{b}\) into the quantum state \(|b\rangle\).
  • Quantum Phase Estimation (QPE): A deep sub-circuit utilizing Hadamard gates, Controlled-Hamiltonian simulations (\(e^{i A t}\)), and the Inverse Quantum Fourier Transform (\(QFT^\dagger\)) to extract eigenvalues.
  • Controlled-Rotation (\(CR_y\)): An ancilla rotation gate controlled by the eigenvalue register, applying \(\theta \propto \arcsin(C/\lambda)\).
  • Inverse QPE (\(QPE^\dagger\)): Uncomputes the eigenvalue register to un-entangle it from the solution.

4. Mathematical Proof & State Evolution

Step 1: Subsystem Initialisation & Spectral Decomposition

The HHL algorithm solves the linear system $A\mathbf{x} = \mathbf{b}$ for a non-singular Hermitian matrix $A$. The goal is to prepare the quantum state $|x\rangle$ proportional to $A^{-1}|b\rangle$.

We initialise three registers: a 1-qubit ancilla ($|0\rangle_a$), a $t$-qubit clock register ($|0\rangle_c^{\otimes t}$), and a target register containing the state $|b\rangle$.

Because $A$ is Hermitian, it has an orthonormal eigenbasis $\{|u_j\rangle\}$ with eigenvalues $\lambda_j$. We decompose $|b\rangle = \sum_j \beta_j |u_j\rangle$, making the initial global state:

\[ |\psi_0\rangle = |0\rangle_a \otimes |0\rangle_c^{\otimes t} \otimes \sum_j \beta_j |u_j\rangle \]

Step 2: Quantum Phase Estimation (Eigenvalue Encoding)

We apply Quantum Phase Estimation (QPE) using the unitary $e^{i A \tau}$ to extract the eigenvalues of $A$ and store them in the clock register.

Because QPE is linear, it acts on the superposition of eigenvectors in $|b\rangle$ simultaneously, heavily entangling the target and clock registers:

\[ |\psi_1\rangle = |0\rangle_a \otimes \sum_j \beta_j |\lambda_j\rangle_c \otimes |u_j\rangle \]

Step 3: Controlled Eigenvalue Inversion (Ancilla Rotation)

The mathematical core of HHL is to invert the eigenvalues ($\beta_j \to \frac{\beta_j}{\lambda_j}$). Since quantum operations must be unitary, we perform a controlled-$R_y$ rotation on the ancilla qubit, conditioned on the eigenvalue $\lambda_j$ in the clock register:

\[ R_y(\theta_j) |0\rangle_a = \sqrt{1 - \left(\frac{C}{\lambda_j}\right)^2} |0\rangle_a + \frac{C}{\lambda_j} |1\rangle_a \]

where $C$ is a normalization constant. Applying this yields a tripartite entangled state:

\[ |\psi_2\rangle = \sum_j \beta_j \left( \sqrt{1 - \frac{C^2}{\lambda_j^2}} |0\rangle_a + \frac{C}{\lambda_j} |1\rangle_a \right) \otimes |\lambda_j\rangle_c \otimes |u_j\rangle \]

Step 4: Inverse QPE & Post-Selection

To decouple the clock register, we apply Inverse QPE ($QPE^\dagger$), erasing the eigenvalues and returning the clock to $|0\rangle_c^{\otimes t}$:

\[ |\psi_3\rangle = \sum_j \beta_j \left( \sqrt{1 - \frac{C^2}{\lambda_j^2}} |0\rangle_a + \frac{C}{\lambda_j} |1\rangle_a \right) \otimes |0\rangle_c^{\otimes t} \otimes |u_j\rangle \]

Finally, we measure the ancilla qubit. We post-select only the outcomes where the ancilla is $|1\rangle$. This instantly collapses the state, annihilating the $|0\rangle_a$ terms and projecting the target register into:

\[ |x\rangle = \frac{1}{\mathcal{N}} \sum_j \frac{C \beta_j}{\lambda_j} |u_j\rangle \propto \sum_j \frac{\beta_j}{\lambda_j} |u_j\rangle \]

Conclusion: Because $A^{-1} = \sum_j \frac{1}{\lambda_j} |u_j\rangle\langle u_j|$, it mathematically follows that $|x\rangle \propto A^{-1}|b\rangle$. The algorithm successfully prepares the exact quantum solution to the linear system in logarithmic time $O(\log N)$.

6. Python Code Implementation

Qiskit Program 
import numpy as np
from qiskit import QuantumCircuit, QuantumRegister, ClassicalRegister, transpile
from qiskit_aer import AerSimulator
from qiskit.quantum_info import Statevector, DensityMatrix, Operator
from qiskit.circuit.library import QFT
from qiskit.visualization import plot_histogram, plot_bloch_multivector, plot_state_qsphere, array_to_latex
from IPython.display import display, Markdown

# ==========================================
# CONFIGURATION
# ==========================================
num_clock_qubits = 2

# 1. Set up Registers & Circuit
ancilla = QuantumRegister(1, name='ancilla')
clock = QuantumRegister(num_clock_qubits, name='clock')
target = QuantumRegister(1, name='target') # 2x2 system
c = ClassicalRegister(1, name='measure')

qc = QuantumCircuit(ancilla, clock, target, c)

# 2. State Preparation U_b (Loading vector b into target register)
qc.ry(np.pi/3, target[0])
qc.barrier(label="State Prep")

# 3. Quantum Phase Estimation (QPE)
qc.h(clock)
# Controlled Hamiltonian simulation placeholder: C-U(e^(iAt))
for i in range(num_clock_qubits):
    qc.cp(np.pi / (2**i), clock[i], target[0]) 
    
# Apply Inverse QFT to clock register
iqft = QFT(num_clock_qubits, inverse=True, do_swaps=True).to_gate()
iqft.name = "IQFT"
qc.append(iqft, clock)
qc.barrier(label="QPE Complete")

# 4. Controlled Eigenvalue Inversion (Conditional Rotation on Ancilla)
# Rotations scaled inversely to the eigenvalues represented by the clock register
qc.cry(np.pi/2, clock[0], ancilla[0])
qc.cry(np.pi/4, clock[1], ancilla[0])
qc.barrier(label="Eigenvalue Inversion")

# 5. Uncomputation / Inverse QPE (Reverse QPE steps)
qft = QFT(num_clock_qubits, inverse=False, do_swaps=True).to_gate()
qft.name = "QFT"
qc.append(qft, clock)

for i in reversed(range(num_clock_qubits)):
    qc.cp(-np.pi / (2**i), clock[i], target[0])
qc.h(clock)
qc.barrier(label="IQPE Complete")

# ==========================================
# EXTRACT EXACT MATH BEFORE MEASUREMENT
# ==========================================
unitary = Operator(qc)
final_state = Statevector(qc)
final_density = DensityMatrix(qc)

# 6. Post-selection Measurement (Measure ancilla)
qc.measure(ancilla, c)

# 7. Execute on AerSimulator
simulator = AerSimulator()
tqc = transpile(qc, simulator)
job = simulator.run(tqc, shots=1024)
result = job.result()

# ==========================================
# REQUIRED COURSEWORK OUTPUTS
# ==========================================

display(Markdown("HHL Algorithm Structural Analysis"))
print(f"Clock qubits: {num_clock_qubits} | Target system: 2x2 | Total qubits: {qc.num_qubits}")

display(Markdown("1. Circuit Visualisation"))
display(qc.draw('mpl'))

display(Markdown("2. Unitary Evolution"))
total_qubits = qc.num_qubits - 1  # Excluding classical register
if total_qubits <= 4:
    print(f"The {2**total_qubits}x{2**total_qubits} unitary matrix describing the structural circuit:")
    display(array_to_latex(unitary.data, prefix="U_{HHL} = ", max_size=16))
else:
    print(f"Unitary matrix omitted: {total_qubits} qubits results in a matrix too large for clean display.")

display(Markdown("3. Quantum State Representation"))
print("Exact Statevector prior to measurement:")
display(final_state.draw('latex'))

print("\nFinal DensityMatrix prior to measurement:")
display(final_density.draw('latex'))

display(Markdown("4. State Visualisation"))
print("State prior to measurement (Bloch Spheres):")
display(plot_bloch_multivector(final_state))

print("\nState prior to measurement (Q-Sphere):")
display(plot_state_qsphere(final_state))

display(Markdown("5. Measurement Analysis (Ancilla Post-Selection)"))

print(f"Raw measurement counts (Ancilla state 0 vs 1): {counts}")

# Verification note

print(f"\nPost-Selection Success Rate: {(success_shots / 1024) * 100:.2f}% of shots successfully inverted the eigenvalue onto the ancilla.")

7. Caveats & Real-World Limits

  • The I/O Bottleneck: HHL assumes you can load the vector \(\vec{b}\) into the quantum state \(|b\rangle\) in \(\mathcal{O}(\log N)\) time. If \(\vec{b}\) is highly arbitrary, preparing this state requires \(\mathcal{O}(N)\) gates, completely wiping out the exponential speedup. True implementation requires hypothetical Quantum RAM (qRAM).
  • Condition Number (\(\kappa\)): If the matrix \(A\) is ill-conditioned (meaning the ratio of the largest to smallest eigenvalue is huge), the rotation constant \(C\) must be exceedingly small. This means the probability of measuring \(|1\rangle\) on the ancilla drops exponentially, forcing you to run the circuit millions of times to get one successful measurement.
  • Measurement Limitations: You cannot extract the full classical vector \(\vec{x}\) out of the quantum computer efficiently. You can only evaluate global, scalar properties of the solution, such as the expectation value \(\langle x | M | x \rangle\) (e.g., calculating the total risk in a portfolio without knowing the exact weights of individual stocks).
  • Dequantization: In 2018, Ewin Tang proved that classical algorithms with access to similar data structures (classical RAM analogous to qRAM) can solve the exact same problem in poly-logarithmic time, effectively "dequantizing" the exponential speedup of HHL for low-rank matrices.

8. Applications

  • Machine Learning: Serves as a primary subroutine for quantum versions of Support Vector Machines (SVMs), Principal Component Analysis (PCA), and linear regression, accelerating the training of large models.
  • Differential Equations: Used in solving massive linearized discretized grids (like the Finite Element Method) for computational fluid dynamics, weather forecasting, and heat transfer simulations.
  • Quantitative Finance: Used to solve massive covariance matrices in Markowitz portfolio optimization, risk modeling, and asset allocation.
