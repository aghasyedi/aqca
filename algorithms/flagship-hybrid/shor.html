Shor's Algorithm

Flagship & Hybrid Models In-Progress

1. Overview & Problem Definition

Shor's Algorithm is arguably the most famous quantum algorithm in existence. It solves the problem of integer factorisation: given a large composite number \(N\), find its prime factors.

The security of modern public-key cryptography (such as RSA) relies entirely on the premise that factoring large numbers is practically impossible for classical computers. Shor's Algorithm proves that a sufficiently powerful quantum computer could break these cryptographic systems exponentially faster than any known classical machine.

Classical Complexity

Sub-exponential

The best classical algorithm (General Number Field Sieve) operates in roughly \(\mathcal{O}\left(e^{1.9 (\log N)^{1/3} (\log \log N)^{2/3}}\right)\) time.

Quantum Speedup

\(\mathcal{O}((\log N)^3)\)

Shor’s algorithm factors the number in polynomial time, yielding a devastating exponential speedup over classical methods.

2. Intuition

Shor's Algorithm is a hybrid algorithm. The genius of Peter Shor was not in trying to factor the number directly on a quantum computer, but in using classical number theory to turn the factorisation problem into a period-finding problem.

  1. Classical Setup: Choose a random number \(a\) (where \(1 < a < N\)). We look at the sequence generated by the function \(f(x) = a^x \pmod N\) for \(x = 0, 1, 2, \dots\). This sequence will eventually repeat. The length of this repeating pattern is called the period, denoted as \(r\).
  2. The Quantum Engine: Finding the period of a sequence over a massive domain is computationally intractable for classical machines. However, quantum computers excel at finding hidden periodicities. By computing \(f(x)\) in a massive superposition and then applying the Inverse Quantum Fourier Transform (\(QFT^\dagger\)), the quantum circuit isolates the exact frequency of the period.
  3. Classical Finish: Once the quantum computer measures the period \(r\), a classical computer uses basic algebra (greatest common divisors) to extract the prime factors of \(N\) almost instantly.

3. Required Gates & Circuit Schematic

  • Hadamard (\(H^{\otimes t}\)): Creates the initial superposition of all possible \(x\) values in the counting register.
  • Controlled Modular Exponentiation (\(CU_{a, N}\)): A complex sequence of controlled gates that computes \(a^x \pmod N\) and stores the result in the target register.
  • Inverse Quantum Fourier Transform (\(QFT^\dagger\)): Extracts the phase information to reveal the period \(r\).

4. Mathematical Proof & State Evolution

Step 1: Initialisation & Superposition

Shor's Algorithm finds the prime factors of an integer \(N\) by finding the period \(r\) of the function \(f(x) = a^x \pmod N\), where \(a\) is coprime to \(N\).

We initialise a \(t\)-qubit counting register (where \(2^t \ge N^2\)) and an \(n\)-qubit target register (where \(2^n \ge N\)):

\[ |\psi_0\rangle = |0\rangle^{\otimes t} \otimes |1\rangle \]

Applying a Hadamard transform \(H^{\otimes t}\) to the counting register prepares an equal superposition of all possible exponents:

\[ |\psi_1\rangle = \frac{1}{\sqrt{2^t}} \sum_{x=0}^{2^t-1} |x\rangle \otimes |1\rangle \]

Step 2: Controlled Modular Exponentiation

A unitary operator \(U_f\) evaluates the modular exponentiation and writes the output to the target register:

\[ |\psi_2\rangle = U_f |\psi_1\rangle = \frac{1}{\sqrt{2^t}} \sum_{x=0}^{2^t-1} |x\rangle \otimes |a^x \pmod N\rangle \]

Because \(a^x \pmod N\) is periodic with period \(r\), this state exhibits massive entanglement. Using the eigenvector basis \(|u_s\rangle\) of the modular multiplication operator, we can rewrite this to reveal the phase kickback:

\[ |\psi_2\rangle = \frac{1}{\sqrt{r}} \sum_{s=0}^{r-1} \left[ \frac{1}{\sqrt{2^t}} \sum_{x=0}^{2^t-1} e^{2\pi i x \frac{s}{r}} |x\rangle \right] \otimes |u_s\rangle \]

Step 3: Inverse Quantum Fourier Transform (IQFT)

To extract the hidden frequency \(\frac{s}{r}\), we apply the Inverse Quantum Fourier Transform (\(QFT^\dagger\)) to the counting register.

Since \(QFT^\dagger |x\rangle = \frac{1}{\sqrt{2^t}} \sum_y e^{-2\pi i \frac{xy}{2^t}} |y\rangle\), the state becomes:

\[ |\psi_3\rangle = \frac{1}{\sqrt{r}} \sum_{s=0}^{r-1} \left[ \frac{1}{2^t} \sum_{y=0}^{2^t-1} \sum_{x=0}^{2^t-1} e^{2\pi i x \left( \frac{s}{r} - \frac{y}{2^t} \right)} |y\rangle \right] \otimes |u_s\rangle \]

Step 4: Measurement & Classical Factoring

The probability of measuring a state \(|y\rangle\) peaks sharply when the interference term is purely constructive, which occurs when:

\[ \frac{y}{2^t} \approx \frac{s}{r} \]

Measuring the counting register gives the integer \(y\). We then use the classical Continued Fractions Algorithm on the known ratio \(\frac{y}{2^t}\) to find the best rational approximation \(\frac{s}{r}\), successfully recovering the period \(r\).

Finally, we compute the prime factors of \(N\) using the greatest common divisor:

\[ \text{Factors} = \gcd(a^{r/2} \pm 1, N) \]

Conclusion: Shor's algorithm provides an exponential speedup by translating factorisation into period finding, using phase kickback and the IQFT to isolate the period in \(O((\log N)^3)\) operations.

5. Interactive Visualisation

  • Modular Exponentiation Graph (Classical): A scatter plot showing the values of \(a^x \pmod N\). The user can visually see the chaotic jumping of numbers that eventually repeats its pattern, illuminating what the period \(r\) actually is.
  • Amplitude Histogram (Quantum): After the \(QFT^\dagger\), the histogram will remain mostly flat at zero, but will feature distinct, sharp "spikes" at multiples of the period. For example, if factoring 15 with \(a=7\) (where \(r=4\)), you will see exactly 4 sharp probability peaks.

6. Python Code Implementation

Qiskit Program 
import math
from fractions import Fraction

from qiskit import QuantumCircuit, QuantumRegister, ClassicalRegister, transpile
from qiskit_aer import AerSimulator
from qiskit.quantum_info import Statevector
from qiskit.circuit.library import QFT
from qiskit.visualization import plot_histogram
from IPython.display import display, Markdown

# ==========================================================
# CONFIGURATION
# ==========================================================

a = 7
N = 15
n_count = 8

# ==========================================================
# Controlled Modular Multiplication
# ==========================================================

def c_amod15(a, power):
    """Controlled multiplication by 7 mod 15."""
    U = QuantumCircuit(4)

    for _ in range(power):
        U.swap(2, 3)
        U.swap(1, 2)
        U.swap(0, 1)

        for q in range(4):
            U.x(q)

    U = U.to_gate()
    U.name = f"{a}^{power} mod 15"
    return U.control()

# ==========================================================
# Registers
# ==========================================================

qr_count = QuantumRegister(n_count, "count")
qr_target = QuantumRegister(4, "target")
cr = ClassicalRegister(n_count, "c")

qc = QuantumCircuit(qr_count, qr_target, cr)

# ==========================================================
# Initialise
# ==========================================================

qc.h(qr_count)
qc.x(qr_target[0])
qc.barrier(label="Init")

# ==========================================================
# Oracle
# ==========================================================

for q in range(n_count):
    # FIXED: Replaced '2 q' with '2**q'
    qc.append(c_amod15(a, 2**q), [qr_count[q]] + list(qr_target))

qc.barrier(label="Oracle")

# ==========================================================
# Inverse QFT
# ==========================================================

iqft = QFT(n_count, inverse=True, do_swaps=True).to_gate()
iqft.name = "IQFT"

qc.append(iqft, qr_count)
qc.barrier(label="IQFT")

# ==========================================================
# Statevector
# ==========================================================

print("Calculating Statevector...")
state = Statevector.from_instruction(qc)
print("Statevector computed successfully.")

# ==========================================================
# Measurement
# ==========================================================

qc.measure(qr_count, cr)

# ==========================================================
# Simulation
# ==========================================================

print("Running Aer Simulator...")

simulator = AerSimulator()
tqc = transpile(qc, simulator)

result = simulator.run(tqc, shots=1024).result()
counts = result.get_counts()

print("Simulation Complete.")

# ==========================================================
# Outputs
# ==========================================================

display(Markdown(f"# Shor's Algorithm (N={N}, a={a})"))

display(Markdown("## 1. Circuit"))
display(qc.draw("mpl"))

display(Markdown("## 2. Quantum State"))

print("Statevector successfully calculated.")
print("\nTotal amplitudes:", len(state))

print("\nFirst 16 amplitudes:\n")
for i, amp in enumerate(state.data[:16]):
    print(f"|{i:012b}> : {amp}")

display(Markdown("## 3. Measurement Histogram"))
display(plot_histogram(counts))

display(Markdown("## 4. Raw Counts"))
print(counts)

display(Markdown("## 5. Classical Post-Processing"))

success = False

for measured_binary in sorted(counts, key=counts.get, reverse=True):

    measured_decimal = int(measured_binary, 2)
    phase = measured_decimal / (2 ** n_count)

    frac = Fraction(phase).limit_denominator(N)
    r = frac.denominator

    print("-" * 60)
    print(f"Measured Binary : {measured_binary}")
    print(f"Decimal         : {measured_decimal}")
    print(f"Estimated Phase : {phase:.6f}")
    print(f"Fraction        : {frac}")
    print(f"Estimated Order : {r}")

    if r % 2 != 0 or r == 0:
        print("Order invalid.\n")
        continue

    # FIXED: Replaced backticks with proper Python exponentiation (**)
    guess1 = math.gcd(a**(r // 2) - 1, N)
    guess2 = math.gcd(a**(r // 2) + 1, N)

    print(f"gcd(a^(r/2)-1,N) = {guess1}")
    print(f"gcd(a^(r/2)+1,N) = {guess2}")

    if guess1 not in [1, N] or guess2 not in [1, N]:
        print("\nSUCCESS!")
        print(f"Factors of {N} are {guess1} and {guess2}")
        success = True
        break
    else:
        print("Only trivial factors obtained.")

if not success:
    print("\nNo non-trivial factors found in this run.")

7. Caveats & Real-World Limits

  • Logical vs. Physical Qubits: Factoring a cryptographically significant number (like a 2048-bit RSA key) requires thousands of perfectly error-corrected logical qubits, which translates to millions of physical qubits.
  • Circuit Depth: The controlled modular exponentiation subroutine (\(CU_{a, N}\)) requires an immense number of physical logic gates to implement. On current Noisy Intermediate-Scale Quantum (NISQ) devices, the quantum state will completely succumb to decoherence long before the circuit finishes evaluating. Currently, Shor's algorithm has only successfully factored very small numbers (like 15 and 21) on real hardware.

8. Applications

  • Breaking RSA Cryptography: The primary application of this algorithm is breaking public-key cryptographic frameworks.
  • Elliptic Curve Cryptography (ECC): A modified version of Shor's algorithm can solve the discrete logarithm problem, breaking ECC even faster than it breaks RSA.
  • Catalyst for Post-Quantum Cryptography: The existence of this algorithm directly spawned the entire field of Post-Quantum Cryptography (PQC), pushing global agencies (like NIST) to standardise new, quantum-resistant lattice-based and hash-based encryption algorithms.
