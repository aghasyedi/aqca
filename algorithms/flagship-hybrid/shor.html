Shor's Algorithm

Flagship & Hybrid Models

1. Overview & Problem Definition

Shor's Algorithm is arguably the most famous quantum algorithm in existence. It solves the problem of integer factorisation: given a large composite number \(N\), find its prime factors.

The security of modern public-key cryptography (such as RSA) relies entirely on the premise that factoring large numbers is practically impossible for classical computers. Shor's Algorithm proves that a sufficiently powerful quantum computer could break these cryptographic systems exponentially faster than any known classical machine.

Classical Complexity

Sub-exponential

The best classical algorithm (General Number Field Sieve) operates in roughly \(\mathcal{O}\left(e^{1.9 (\log N)^{1/3} (\log \log N)^{2/3}}\right)\) time.

Quantum Speedup

\(\mathcal{O}((\log N)^3)\)

Shor’s algorithm factors the number in polynomial time, yielding a devastating exponential speedup over classical methods.

2. Intuition

Shor's Algorithm is a hybrid algorithm. The genius of Peter Shor was not in trying to factor the number directly on a quantum computer, but in using classical number theory to turn the factorisation problem into a period-finding problem.

  1. Classical Setup: Choose a random number \(a\) (where \(1 < a < N\)). We look at the sequence generated by the function \(f(x) = a^x \pmod N\) for \(x = 0, 1, 2, \dots\). This sequence will eventually repeat. The length of this repeating pattern is called the period, denoted as \(r\).
  2. The Quantum Engine: Finding the period of a sequence over a massive domain is computationally intractable for classical machines. However, quantum computers excel at finding hidden periodicities. By computing \(f(x)\) in a massive superposition and then applying the Inverse Quantum Fourier Transform (\(QFT^\dagger\)), the quantum circuit isolates the exact frequency of the period.
  3. Classical Finish: Once the quantum computer measures the period \(r\), a classical computer uses basic algebra (greatest common divisors) to extract the prime factors of \(N\) almost instantly.

3. Required Gates & Circuit Schematic

  • Hadamard (\(H^{\otimes t}\)): Creates the initial superposition of all possible \(x\) values in the counting register.
  • Controlled Modular Exponentiation (\(CU_{a, N}\)): A complex sequence of controlled gates that computes \(a^x \pmod N\) and stores the result in the target register.
  • Inverse Quantum Fourier Transform (\(QFT^\dagger\)): Extracts the phase information to reveal the period \(r\).

4. Mathematical Proof & State Evolution

Step 1: Initialisation

We use two registers. The upper counting register has \(t\) qubits (chosen such that \(N^2 \le 2^t < 2N^2\)) initialised to \(|0\rangle\). The lower target register has \(n\) qubits (where \(2^n \ge N\)) initialised to the computational state \(|1\rangle\).

\(|\psi_0\rangle = |0\rangle^{\otimes t} \otimes |1\rangle^{\otimes n}\)

Step 2: Superposition

We apply \(H^{\otimes t}\) to the counting register:

\(|\psi_1\rangle = \frac{1}{\sqrt{2^t}} \sum_{x=0}^{2^t-1} |x\rangle \otimes |1\rangle\)

Step 3: Controlled Modular Exponentiation

We apply the unitary operator \(U_x\) which computes \(a^x \pmod N\) in the target register. This highly entangles the two registers:

\(|\psi_2\rangle = \frac{1}{\sqrt{2^t}} \sum_{x=0}^{2^t-1} |x\rangle \otimes |a^x \pmod N\rangle\)

Step 4: Inverse Quantum Fourier Transform

Because the function \(a^x \pmod N\) is periodic with period \(r\), the amplitudes in the counting register possess a repeating wave-like structure. We apply the \(QFT^\dagger\) to the counting register to extract this frequency.

The mathematics of the \(QFT^\dagger\) causes total destructive interference for almost all states, and massive constructive interference at states \(|y\rangle\) that are integer multiples of \(2^t / r\):

\(|\psi_3\rangle \approx \sum_{s=0}^{r-1} \left( \text{amplitude} \right) \left| y \approx s \frac{2^t}{r} \right\rangle\)

Measurement

When we measure the counting register, we observe an integer \(y\) that is very close to a multiple of \(2^t / r\). This gives us the ratio:

\(\frac{y}{2^t} \approx \frac{s}{r}\)

A classical computer then uses the Continued Fractions Algorithm on the known fraction \(y/2^t\) to find the denominator \(r\). Once \(r\) is found (and assuming \(r\) is even), the prime factors are calculated via:

\(\text{Factors} = \gcd(a^{r/2} \pm 1, N)\)

5. Interactive Visualisation

  • Modular Exponentiation Graph (Classical): A scatter plot showing the values of \(a^x \pmod N\). The user can visually see the chaotic jumping of numbers that eventually repeats its pattern, illuminating what the period \(r\) actually is.
  • Amplitude Histogram (Quantum): After the \(QFT^\dagger\), the histogram will remain mostly flat at zero, but will feature distinct, sharp "spikes" at multiples of the period. For example, if factoring 15 with \(a=7\) (where \(r=4\)), you will see exactly 4 sharp probability peaks.

6. Python Code Implementation

From Scratch (NumPy) 
import numpy as np
import math

def classical_shor_simulation(N, a):
    """
    Simulates the mathematical logic of Shor's algorithm for small N.
    """
    if math.gcd(a, N) != 1:
        return f"Lucky guess! Factor is {math.gcd(a, N)}"
        
    # 1. Quantum subroutine simulation: Finding the period 'r'
    # In a real quantum computer, this is done via QPE and modular exponentiation.
    # Here, we classically compute the period for the sake of simulation.
    r = 1
    while (a**r) % N != 1:
        r += 1
        
    print(f"Quantum Circuit found period r = {r}")
    
    # 2. Classical Post-processing
    if r % 2 != 0:
        return "Failed: Period is odd. Try a different 'a'."
    
    val = (a**(r//2)) % N
    if val == N - 1:
        return "Failed: Trivial factors found. Try a different 'a'."
        
    factor1 = math.gcd(val - 1, N)
    factor2 = math.gcd(val + 1, N)
    
    return f"Success! The factors of {N} are {factor1} and {factor2}"

# Factor 15 using a=7
print(classical_shor_simulation(15, 7))
Framework (Qiskit) 
from qiskit import QuantumCircuit
from qiskit.circuit.library import QFT
from qiskit_aer import AerSimulator
import math

# Factoring N=15, a=7 requires a highly specific, hardcoded modular exponentiation 
# circuit on NISQ simulators. Here we build the theoretical structure.

def c_amod15(a, power):
    """Controlled modular exponentiation for a=7, N=15 (Simplified Oracle)."""
    U = QuantumCircuit(4)        
    for _iteration in range(power):
        U.swap(2, 3)
        U.swap(1, 2)
        U.swap(0, 1)
        for q in range(4):
            U.x(q)
    U = U.to_gate()
    U.name = f"{a}^{power} mod 15"
    return U.control()

def shors_circuit_15():
    n_count = 8  # Number of counting qubits
    qc = QuantumCircuit(n_count + 4, n_count)
    
    # 1. Initialise counting qubits in superposition
    qc.h(range(n_count))
    
    # 2. Initialise target register to |1>
    qc.x(n_count)
    
    # 3. Apply Controlled Modular Exponentiation
    for q in range(n_count):
        qc.append(c_amod15(7, 2**q), [q] + list(range(n_count, n_count+4)))
        
    # 4. Apply Inverse QFT to counting register
    qc.append(QFT(n_count, inverse=True, do_swaps=True).to_gate(), range(n_count))
    
    # 5. Measure
    qc.measure(range(n_count), range(n_count))
    return qc

circuit = shors_circuit_15()
print("Shor's Circuit architecture built successfully.")

7. Caveats & Real-World Limits

  • Logical vs. Physical Qubits: Factoring a cryptographically significant number (like a 2048-bit RSA key) requires thousands of perfectly error-corrected logical qubits, which translates to millions of physical qubits.
  • Circuit Depth: The controlled modular exponentiation subroutine (\(CU_{a, N}\)) requires an immense number of physical logic gates to implement. On current Noisy Intermediate-Scale Quantum (NISQ) devices, the quantum state will completely succumb to decoherence long before the circuit finishes evaluating. Currently, Shor's algorithm has only successfully factored very small numbers (like 15 and 21) on real hardware.

8. Applications

  • Breaking RSA Cryptography: The primary application of this algorithm is breaking public-key cryptographic frameworks.
  • Elliptic Curve Cryptography (ECC): A modified version of Shor's algorithm can solve the discrete logarithm problem, breaking ECC even faster than it breaks RSA.
  • Catalyst for Post-Quantum Cryptography: The existence of this algorithm directly spawned the entire field of Post-Quantum Cryptography (PQC), pushing global agencies (like NIST) to standardise new, quantum-resistant lattice-based and hash-based encryption algorithms.
