Quantum Approximate Optimisation Algorithm (QAOA)

Flagship & Hybrid Models

1. Overview & Problem Definition

The Quantum Approximate Optimisation Algorithm (QAOA) is a hybrid quantum-classical algorithm designed to find approximate solutions to NP-hard combinatorial optimisation problems, such as Max-Cut, the Travelling Salesperson Problem, and Boolean Satisfiability (3-SAT).

Rather than attempting to calculate exact solutions deterministically, QAOA encodes the cost function of a classical optimisation problem into a problem Hamiltonian (\(H_C\)). It then uses a parametrised, layered quantum circuit to prepare a quantum state that concentrates probability amplitude around bitstrings that satisfy or optimize the cost function.

Classical Complexity

NP-hard (\(\mathcal{O}(2^N)\) brute force)

Finding exact global optima for worst-case instances scales exponentially with graph size \(N\).

Quantum Speedup

Heuristic / NISQ-friendly

Provides polynomial-to-superpolynomial approximate solutions on near-term, shallow-depth quantum processors.

2. Intuition

QAOA is a discrete, shallow-circuit approximation of the Quantum Adiabatic Theorem.

The Quantum Adiabatic Theorem states that if you start a quantum system in the known, easy-to-prepare ground state of an initial "mixer" Hamiltonian (\(H_M\)) and evolve the system slowly enough toward a target "problem" Hamiltonian (\(H_C\)), the system will remain in its ground state—which at the end corresponds to the optimal classical solution.

Because continuous adiabatic evolution requires circuit depths far too long for modern hardware, QAOA breaks this evolution down into \(p\) discrete alternating layers (known as circuit depth \(p\)):

  1. Apply Problem Phase Shift: Apply the cost Hamiltonian \(H_C\) for a duration \(\gamma_k\). This shifts the quantum phases of candidate solutions based on how well they satisfy the constraints.
  2. Apply Mixer Phase Shift: Apply the mixer Hamiltonian \(H_M\) for a duration \(\beta_k\). This drives quantum interference between candidate solutions, allowing amplitudes to flow toward better configurations.
  3. Classical Optimisation: A classical loop evaluates the average cost of the measured bitstrings and adjusts the parameters \((\vec{\gamma}, \vec{\beta})\) to guide the circuit toward higher-quality solutions in subsequent runs.

3. Required Gates & Circuit Schematic

  • Hadamard (\(H^{\otimes n}\)): Prepares the initial uniform superposition \(|+\rangle^{\otimes n}\), which is the ground state of the standard mixer Hamiltonian.
  • Cost Unitary (\(U(H_C, \gamma) = e^{-i \gamma H_C}\)): Implemented using entangling two-qubit \(RZ\) or \(CX\)-\(RZ\)-\(CX\) sub-circuits across graph edges to penalize or reward candidate bitstrings.
  • Mixer Unitary (\(U(H_M, \beta) = e^{-i \beta H_M}\)): Implemented using single-qubit \(RX(2\beta)\) rotations across all qubits.

4. Mathematical Proof & State Evolution

Step 1: Initial State Preparation

The system starts in the ground state of the mixer \(H_M = \sum_{i=1}^n X_i\), which is the equal superposition over all \(2^n\) computational basis states:

\(|\gamma, \beta\rangle_0 = |+\rangle^{\otimes n} = \frac{1}{\sqrt{2^n}} \sum_{x \in \{0,1\}^n} |x\rangle\)

Step 2: Problem & Mixer Layering

For a depth-\(p\) ansatz, we alternately apply the unitaries \(U(H_C, \gamma_k) = e^{-i \gamma_k H_C}\) and \(U(H_M, \beta_k) = e^{-i \beta_k H_M}\) for \(k = 1, \dots, p\):

\(|\vec{\gamma}, \vec{\beta}\rangle = \left( \prod_{k=1}^p e^{-i \beta_k H_M} e^{-i \gamma_k H_C} \right) |+\rangle^{\otimes n}\)

For a standard Max-Cut problem on a graph \(G=(V,E)\), the cost Hamiltonian is \(H_C = \frac{1}{2} \sum_{(i,j) \in E} (I - Z_i Z_j)\). The entangling term \(e^{i \frac{\gamma}{2} Z_i Z_j}\) applies a relative phase depending on whether qubits \(i\) and \(j\) are in the same or opposite computational basis states.

The mixer unitary simplifies to independent single-qubit rotations:

\(e^{-i \beta H_M} = \prod_{i=1}^n e^{-i \beta X_i} = \prod_{i=1}^n RX(2\beta)_i\)

Step 3: Expectation Value Evaluation

The goal of the algorithm is to maximize the expected value of the cost function:

\(F_p(\vec{\gamma}, \vec{\beta}) = \langle \vec{\gamma}, \vec{\beta} | H_C | \vec{\gamma}, \vec{\beta} \rangle\)

Measurement

We run the quantum circuit for a fixed \((\vec{\gamma}, \vec{\beta})\) and measure all qubits in the computational basis (\(Z\)-basis) over multiple shots to construct a probability distribution over sample bitstrings. A classical optimiser evaluates \(F_p\) from the sample results and updates \((\vec{\gamma}, \vec{\beta})\) until convergence.

6. Python Code Implementation

From Scratch (NumPy) 
import numpy as np
from scipy.optimize import minimize

def simulate_qaoa_maxcut_2node():
    """
    Simulates QAOA (p=1) for a 2-node 1-edge Max-Cut problem using pure NumPy.
    Hamiltonian H_C = 0.5 * (I - Z_0 Z_1)
    """
    # Pauli Matrices
    I = np.eye(2, dtype=complex)
    Z = np.array([[1, 0], [0, -1]], dtype=complex)
    X = np.array([[0, 1], [1, 0]], dtype=complex)
    
    Z0Z1 = np.kron(Z, Z)
    X0 = np.kron(X, I)
    X1 = np.kron(I, X)
    
    # Cost Hamiltonian H_C and Mixer H_M
    H_C = 0.5 * (np.eye(4, dtype=complex) - Z0Z1)
    H_M = X0 + X1
    
    # Initial state |++>
    plus = np.array([[1], [1]], dtype=complex) / np.sqrt(2)
    psi_0 = np.kron(plus, plus)
    
    def cost_expectation(params):
        gamma, beta = params[0], params[1]
        
        # Matrix exponentials for unitaries
        # e^{-i gamma H_C}
        evals_C, evecs_C = np.linalg.eigh(H_C)
        U_C = evecs_C @ np.diag(np.exp(-1j * gamma * evals_C)) @ evecs_C.conj().T
        
        # e^{-i beta H_M}
        evals_M, evecs_M = np.linalg.eigh(H_M)
        U_M = evecs_M @ np.diag(np.exp(-1j * beta * evals_M)) @ evecs_M.conj().T
        
        # Total state |gamma, beta> = U_M * U_C * |psi_0>
        psi = U_M @ U_C @ psi_0
        
        # Calculate <psi| H_C |psi>
        expectation = (psi.conj().T @ H_C @ psi)[0, 0].real
        return -expectation  # Minimize negative cost to maximize cut
        
    # Classical Optimization
    res = minimize(cost_expectation, x0=[0.5, 0.5], method='COBYLA')
    max_cut_val = -res.fun
    
    return max_cut_val, res.x

max_cut, optimal_params = simulate_qaoa_maxcut_2node()
print(f"Max-Cut Expectation Value: {max_cut:.4f} (Ideal = 1.0)")
print(f"Optimal Parameters (gamma, beta): {optimal_params}")
Framework (Qiskit) 
from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator
import numpy as np

def create_qaoa_maxcut_circuit(edges, num_nodes, gamma, beta):
    """Constructs a p=1 QAOA circuit for Max-Cut on an arbitrary graph."""
    qc = QuantumCircuit(num_nodes, num_nodes)
    
    # 1. Initialise superposition |+>^n
    qc.h(range(num_nodes))
    qc.barrier()
    
    # 2. Problem Layer U(H_C, gamma)
    for u, v in edges:
        qc.cx(u, v)
        qc.rz(2 * gamma, v)
        qc.cx(u, v)
    qc.barrier()
    
    # 3. Mixer Layer U(H_M, beta)
    for node in range(num_nodes):
        qc.rx(2 * beta, node)
    qc.barrier()
    
    # 4. Measurement
    qc.measure(range(num_nodes), range(num_nodes))
    return qc

# Example graph: 3-node triangle graph (0-1, 1-2, 2-0)
edges = [(0, 1), (1, 2), (2, 0)]
circuit = create_qaoa_maxcut_circuit(edges, num_nodes=3, gamma=0.3, beta=0.4)

simulator = AerSimulator()
counts = simulator.run(circuit, shots=1024).result().get_counts()
print("Sample Measurement Outcomes:", counts)

7. Caveats & Real-World Limits

  • Barren Plateaus & Local Minima: Like VQE, high-dimensional parameter landscapes for large \(p\) or large qubit counts suffer from vanishing gradients and non-convex energy landscapes, causing classical optimisers to get trapped in suboptimal local minima.
  • Hardware Connectivity Limits: Real hardware topology rarely matches arbitrary graph structures. Mapping non-adjacent graph edges requires inserting additional \(SWAP\) gates, significantly increasing circuit depth and gate noise.
  • Classical Benchmark Comparison: Highly efficient classical approximation techniques (such as the Goemans-Williamson algorithm, which guarantees an approximation ratio of \(\approx 0.878\) for Max-Cut in polynomial time) set a high performance baseline that near-term NISQ hardware struggles to surpass.

8. Applications

  • Network Partitioning & Portfolio Optimisation: Solving Max-Cut and graph clustering problems in telecommunications routing and financial asset diversification.
  • Logistics & Scheduling: Mapping constraints in vehicle routing problems (VRP) and job-shop scheduling to Ising Hamiltonians.
  • Combinatorial Satisfiability: Solving constraint satisfaction problems (CSPs) and 3-SAT instances across quantum-assisted scheduling domains.
