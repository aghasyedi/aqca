# AQCA: All Quantum Computing Algorithms

AQCA is a classic government/academic information portal serving as an educational atlas and simulation platform for quantum computing. 

## Project Structure

This frontend skeleton is built strictly with HTML5, CSS3, and Vanilla JavaScript.
It employs a classic academic portal design, primarily featuring a permanent left-sidebar navigation on desktop, with an overarching brand identity in `#000f91`.

### Directories
- `algorithms/`: Contains individual algorithm HTML files organized by categories (foundations, oracle-based, phase-amplitude, flagship-hybrid, fault-tolerance).
- `css/`: Stylesheets (`style.css` for globals, `responsive.css` for layout queries, `algorithm.css` for standardized template structures).
- `js/`: Vanilla JS for UI interaction.
- `assets/`: Images, icons, and logos.

## Next Steps
Future iterations will populate the algorithm template containers with fully-fledged, interactive quantum simulations, mathematical derivations, and implementations (NumPy and Qiskit).
