Quantum Parallelism

1. The Concept of Quantum Parallelism

Quantum parallelism is a fundamental feature of many quantum algorithms. It refers to the ability of a quantum computer to evaluate a function \(f(x)\) for many different values of \(x\) simultaneously by exploiting the principle of quantum superposition.

While classical computers must evaluate a function sequentially (or use multiple processors to evaluate it in parallel), a quantum computer uses a single processing unit (the quantum circuit) to act on all possible inputs at once.

2. Creating the Superposition

To evaluate a function on all possible \(n\)-bit inputs, we must first create a state containing all those inputs. We start with an \(n\)-qubit register initialized to the all-zero state, \(|0\rangle^{\otimes n}\).

We then apply a Hadamard gate (\(H\)) to every single qubit. The Hadamard gate creates an equal superposition of \(|0\rangle\) and \(|1\rangle\) for each qubit. Because the tensor product distributes over addition, the result is an equal superposition of all \(2^n\) possible computational basis states:

\(|\psi_{\text{in}}\rangle = H^{\otimes n} |0\rangle^{\otimes n} = \frac{1}{\sqrt{2^n}} \sum_{x=0}^{2^n-1} |x\rangle\)

3. Evaluating the Oracle

With our input register prepared in this massive superposition, we introduce an ancillary target qubit \(|y\rangle\), initialized to \(|0\rangle\). We then apply a Boolean Oracle \(U_f\) to the joint system.

Because quantum mechanics is strictly linear, the oracle operator distributes across the sum, evaluating the function for every single term in the superposition simultaneously in a single physical step:

\(U_f \left( \frac{1}{\sqrt{2^n}} \sum_{x=0}^{2^n-1} |x\rangle \right) |0\rangle = \frac{1}{\sqrt{2^n}} \sum_{x=0}^{2^n-1} |x\rangle |f(x)\rangle\)

The Exponential Explosion

The scale of this parallelism is difficult to comprehend. For \(n = 10\), we evaluate 1,024 inputs at once. For \(n = 50\), we evaluate 1.1 million trillion inputs. For \(n = 300\), we are evaluating more inputs simultaneously than there are estimated atoms in the observable universe. A classical computer would require the age of the universe to loop through this many inputs; the quantum computer does it in a fraction of a millisecond.

4. The Big Caveat: Wavefunction Collapse

If quantum parallelism is so powerful, why don't quantum computers instantly solve every problem? The issue arises when we try to extract the answers. To read the output, we must perform a measurement.

According to the laws of Wavefunction Collapse, measuring the state \(\sum |x\rangle |f(x)\rangle\) will instantly collapse the massive superposition into exactly one random basis state \(|x\rangle|f(x)\rangle\). All other \(2^n - 1\) evaluations are permanently destroyed.

You performed \(2^n\) calculations, but you are only allowed to read exactly one of them. This is no better than taking a classical computer, choosing a random input \(x\), and evaluating it once.

5. The Solution: Quantum Interference

To extract useful global information about the function (such as finding a specific target, or determining a period), quantum algorithms combine parallelism with Interference.

By using the Phase Kickback Mechanism, algorithms apply negative phases to certain states. When subsequent Hadamard gates (or other operators) are applied, the probability amplitudes of incorrect answers cancel each other out (destructive interference), while the probability amplitudes of the correct answers reinforce each other (constructive interference).

When the final measurement is taken, the system does not output a random answer, but rather outputs the desired solution with near 100% probability. Quantum parallelism generates the data, but interference is what makes it accessible.
