The Kickback Mechanism

1. Introduction to Phase Kickback

The Phase Kickback mechanism (often just called "kickback") is arguably the most important algorithmic building block in quantum computing. It allows a quantum computer to transfer the result of a function evaluation from an ancillary target register directly into the phase of the input register.

Without kickback, algorithms like Deutsch-Jozsa, Bernstein-Vazirani, Simon's algorithm, and Grover's search simply could not exist. It is the bridge that converts a Boolean Oracle into a Phase Oracle.

2. The Mathematical Derivation

Suppose we are given a Boolean oracle \(U_f\) for a function \(f(x)\), which operates on an input register \(|x\rangle\) and a target qubit \(|y\rangle\):

\(U_f |x\rangle|y\rangle = |x\rangle|y \oplus f(x)\rangle\)

To trigger the kickback mechanism, the experimentalist must initialize the target qubit \(|y\rangle\) into the negative superposition state, known as the \(|-\rangle\) state:

\(|-\rangle = \frac{1}{\sqrt{2}} (|0\rangle - |1\rangle)\)

Now, let us apply the oracle \(U_f\) to the joint system \(|x\rangle \otimes |-\rangle\). Because quantum operators are linear, we can distribute \(U_f\) inside the superposition:

\begin{align*} U_f \Big( |x\rangle \otimes |-\rangle \Big) &= U_f \left( |x\rangle \otimes \frac{|0\rangle - |1\rangle}{\sqrt{2}} \right) \\[1em] &= \frac{1}{\sqrt{2}} \Big( U_f|x\rangle|0\rangle - U_f|x\rangle|1\rangle \Big) \\[1em] &= \frac{1}{\sqrt{2}} \Big( |x\rangle|0 \oplus f(x)\rangle - |x\rangle|1 \oplus f(x)\rangle \Big) \end{align*}

To resolve this, we must evaluate the expression for the two possible binary values of the function \(f(x)\).

Case 1: If \(f(x) = 0\)

If the function evaluates to zero, \(0 \oplus 0 = 0\) and \(1 \oplus 0 = 1\). The state becomes:

\(\frac{1}{\sqrt{2}} \Big( |x\rangle|0\rangle - |x\rangle|1\rangle \Big) = |x\rangle \otimes \frac{|0\rangle - |1\rangle}{\sqrt{2}} = |x\rangle \otimes |-\rangle\)

The state remains completely unchanged. This is equivalent to multiplying by \(+1\).

Case 2: If \(f(x) = 1\)

If the function evaluates to one, \(0 \oplus 1 = 1\) and \(1 \oplus 1 = 0\). The state becomes:

\(\frac{1}{\sqrt{2}} \Big( |x\rangle|1\rangle - |x\rangle|0\rangle \Big)\)

Notice that the order of the terms has swapped! We can factor out a \(-1\) to restore the original order:

\(- \frac{1}{\sqrt{2}} \Big( |x\rangle|0\rangle - |x\rangle|1\rangle \Big) = - \Big( |x\rangle \otimes |-\rangle \Big)\)

The state has gained a global phase of \(-1\).

3. The Unified Kickback Equation

We can combine Case 1 and Case 2 into a single, elegant mathematical equation using an exponent:

\(U_f |x\rangle |-\rangle = (-1)^{f(x)} |x\rangle |-\rangle\)

Why is it called "Kickback"?

Look closely at the equation above. The target qubit \(|-\rangle\) did not change. It started as \(|-\rangle\) and it ended as \(|-\rangle\). However, a phase of \((-1)^{f(x)}\) has appeared.

Because the target qubit is factored out, this phase factor physically acts upon the input register \(|x\rangle\). The information \(f(x)\) was computed on the target qubit, but it got "kicked back" up into the phase of the control qubit.

4. Eigenvalue Interpretation

An advanced way to understand phase kickback is through linear algebra and eigenvectors.

When \(f(x) = 1\), the Boolean oracle acts as a Pauli-X gate (a quantum NOT gate) applied to the target qubit. The Pauli-X gate flips \(|0\rangle\) to \(|1\rangle\) and vice versa.

What are the eigenvectors of the Pauli-X matrix? They are the \(|+\rangle\) and \(|-\rangle\) states:

  • \(X|+\rangle = +1 |+\rangle\) (Eigenvalue of +1)
  • \(X|-\rangle = -1 |-\rangle\) (Eigenvalue of -1)

Because we prepared the target qubit in the \(|-\rangle\) state, applying the oracle is equivalent to applying an operation to its own eigenvector. The target state cannot change, but it emits its eigenvalue (\(-1\)) which factors out to the front of the joint tensor product.

5. A Simple Example: The CNOT Gate

The CNOT (Controlled-NOT) gate is the simplest example of a boolean oracle, where \(f(x) = x\). It flips the target if the control is \(|1\rangle\).

If we prepare the control in \(|+\rangle\) and the target in \(|-\rangle\):

\(\text{CNOT} \Big( |+\rangle \otimes |-\rangle \Big) = \text{CNOT} \left( \frac{|0\rangle + |1\rangle}{\sqrt{2}} \otimes |-\rangle \right)\)

Distributing this out:

\(\frac{1}{\sqrt{2}} \Big( \text{CNOT}|0\rangle|-\rangle + \text{CNOT}|1\rangle|-\rangle \Big)\)

When the control is \(|0\rangle\), nothing happens. When the control is \(|1\rangle\), the target \(|-\rangle\) emits a \(-1\) phase:

\(\frac{1}{\sqrt{2}} \Big( |0\rangle|-\rangle - |1\rangle|-\rangle \Big) = \left( \frac{|0\rangle - |1\rangle}{\sqrt{2}} \right) \otimes |-\rangle = |-\rangle \otimes |-\rangle\)

The target qubit stayed \(|-\rangle\), but the control qubit transformed from \(|+\rangle\) into \(|-\rangle\). The phase was kicked back, completely altering the state of the control qubit without ever touching it directly!
